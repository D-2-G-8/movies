# Nightwave

Личный кинотеатр в формате линейного ТВ. Зритель выбирает тематический канал, а сервис сам решает, что сейчас показывать, и при необходимости вставляет между программами трейлеры или короткие ролики.

## Что уже работает

- русскоязычные страницы кинотеатра, канала и Студии;
- каналы «Кино», «Сериалы» и «Мультфильмы» с русской озвучкой;
- воспроизведение официальных роликов и программ с YouTube;
- автоматический и ручной переход к следующей программе;
- режимы показа по порядку и в случайном порядке;
- правила повторов и вставок между программами;
- Студия (`/admin`) для управления каналами, контентом и источниками;
- импорт карточки фильма, сериала или мультфильма по ссылке Кинопоиска;
- SQLite, начальные данные и история воспроизведения.

## Начальные данные

Команда `npm run db:seed` очищает демонстрационные данные и создаёт три канала:

- «Кино» — «Бриллиантовая рука» с официального канала «Мосфильм»;
- «Сериалы» — «Батальоны просят огня. 2 серия» с официального канала «Мосфильм»;
- «Мультфильмы» — подборка «Простоквашино» с официального канала «Союзмультфильм».

Все три примера используют русскую звуковую дорожку. Локальные видеофайлы и RUTUBE не используются.

## Импорт с Кинопоиска

В разделе **Контент** можно вставить ссылку вида:

```text
https://www.kinopoisk.ru/film/4860213/
```

Сервис открывает только страницу `kinopoisk.ru`, читает публичные метаданные и показывает заполненную карточку перед сохранением. Импортируются:

- русское и оригинальное названия;
- тип контента и год;
- длительность и описание;
- постер;
- жанры и страны;
- режиссёры и актёры;
- рейтинг, количество оценок и возрастной рейтинг.

Перед добавлением название, тип, год, длительность и описание можно поправить. Повторный импорт той же карточки определяется по идентификатору Кинопоиска и не создаёт дубль.

Кинопоиск используется только для метаданных. Видео, временные ссылки и защищённые потоки с него не копируются. Чтобы карточка появилась в эфире, ей отдельно подключается легальный источник в разделе **Источники**, а затем она добавляется в расписание канала.

## Источники видео

Карточка контента и источник видео разделены. У одного материала может быть несколько источников; сервис выбирает активный источник с наибольшим приоритетом.

Поддерживаются:

- `YOUTUBE` — идентификатор видео YouTube, воспроизведение во встроенном плеере;
- `DIRECT_URL` — прямая ссылка на совместимое с браузером видео или iframe;
- `INTERNET_ARCHIVE` — публичный идентификатор записи Internet Archive;
- `EXTERNAL` — заготовка для следующего внешнего провайдера.

Для YouTube в поле **ID источника** указывается часть ссылки после `youtu.be/` или параметр `v`, например `M9cGHdVbNXI`.

## Работа через Студию

### Добавить карточку

1. Откройте `/admin` и раздел **Контент**.
2. Вставьте ссылку Кинопоиска и нажмите **Получить данные**.
3. Проверьте автоматически заполненную карточку.
4. Нажмите **Добавить в библиотеку**.

Карточку также можно создать вручную в форме ниже.

### Подключить видео и канал

1. В разделе **Источники** выберите карточку и провайдера.
2. Для YouTube укажите ID видео, для прямой ссылки — адрес видео.
3. В разделе **Каналы** добавьте карточку в расписание нужного канала.

### Добавить трейлер или ролик

1. В разделе **Реклама и трейлеры** создайте ролик с прямой ссылкой.
2. Назначьте его нужному каналу.
3. В настройках канала включите трейлеры или рекламу и укажите количество вставок.

## API

Публичные маршруты:

```text
GET  /api/channels
GET  /api/channels/:id
GET  /api/channels/:id/playback
GET  /api/channels/:id/now-playing
POST /api/channels/:id/next
```

Внутренние маршруты Студии:

```text
POST /api/internal/media/import/kinopoisk
/api/internal/channels
/api/internal/channels/:id/rules
/api/internal/channels/:id/media
/api/internal/channels/:id/ads
/api/internal/media
/api/internal/media/:id/sources
/api/internal/sources/:id
/api/internal/ads
```

У внутренних маршрутов пока нет авторизации. Перед публикацией сервиса в сеть нужно добавить вход администратора и проверку доступа.

## Техническая часть

- Next.js 16, App Router, TypeScript и React 19;
- Prisma 6 и SQLite;
- слой провайдеров в `src/lib/providers`;
- планировщик эфира в `src/lib/playback.ts`;
- схема и начальные данные в `prisma/`.

Проект не обходит DRM, токены доступа и защиты видеосервисов. Прямой источник должен разрешать воспроизведение во встроенном браузерном плеере.
